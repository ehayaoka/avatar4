# 表情で動くキャラクター（Web版）

カメラで顔を判定し、表情と口の開閉に合わせてキャラクター画像を切り替えます（音声機能はありません）。
5感情（通常・喜び・怒り・困り・驚き）× 口2段階（閉・開）＝ 10枚の画像を、各自のブラウザからアップロードして使います。

- 顔判定は Google MediaPipe Face Landmarker（Apache-2.0）を使い、**各自のパソコンのブラウザ内で処理**します。カメラ映像はどこにも送信されません。
- 画像・設定は、そのブラウザの中（IndexedDB / localStorage）だけに保存されます。
- サーバーはファイルを配るだけなので、15人が同時に使っても負荷はほぼかかりません。
- 推奨ブラウザ：パソコンの Chrome または Edge。カメラを使うため **https:// のURLで開く必要があります**（GitHub Pages は https なのでそのまま使えます）。

## 公開方法：GitHub Pages
1. GitHub で新しいリポジトリ（例：`kao-chara`）を作り、このフォルダの **中身** をアップロード（Add file → Upload files にフォルダごとドラッグ）。
   ※ `vendor/mediapipe/wasm/vision_wasm_internal.wasm` は約14MBです（ブラウザからのアップロード上限25MB以内）。
2. Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `(root)` にして Save。
3. 数分後に `https://<ユーザー名>.github.io/kao-chara/` で開けます。
   ※ 無料プランでは公開リポジトリになり、`samples/` の画像も公開されます。不要なら `samples/` を削除してください（「サンプル」ボタンが使えなくなるだけです）。

さくらのレンタルサーバに置く場合は、`/wayo/la/kao/` など **新しいフォルダ** にアップロードしてください（既存アプリを上書きしないため）。

## 判定のしくみ
| 表情 | 主に見ているところ |
|---|---|
| 喜び | 口角が上がる |
| 怒り | 眉が下がる・目を細める |
| 困り | 眉頭だけが上がる |
| 驚き | 眉全体が上がる・目を見開く |
| 通常 | どれもしきい値を越えないとき |
| 口の開閉 | あごの開き |

- 「いつもの顔を登録」で各自の真顔を基準にし、個人差を補正します。
- 各表情のしきい値はスライダーで調整でき、ブラウザに保存されます。
- キー `1`〜`5` で表情を固定、`0` で自動判定に戻ります（口はカメラのまま動きます）。

## ファイル構成
- `index.html` 操作画面（カメラ・判定・プレビュー） / `stage.html` 出力画面（1920×1080、ATEMへ）
- `js/detect.js` 表情の判定 / `js/app.js` 操作画面 / `js/render.js` 描画 / `js/common.js` 感情の定義・画像保存
- `vendor/mediapipe/` 顔判定ライブラリとモデル（外部CDNに依存しないよう同梱）
- `samples/majo/` 「サンプル」ボタンで読み込む画像（任意）
- `学生向け_使い方.txt` 配布用の説明

キャラクターファイル（`.chara.json`）は「しゃべるキャラクター（Web版）」と同じ形式で、相互に読み込めます。
